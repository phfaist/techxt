About techxt

Techxt — LaTeX to unicode text converter

Convert LaTeX code (approximately) into readable plain text: \emph{hi} becomes ℎ𝑖, \"o becomes ö, $\sum_{i=1}^n x_i$ becomes ∑ᵢ₌₁ⁿ 𝑥ᵢ, an itemize becomes a bulleted list, and a tabular becomes an aligned text table.

Rust libraries, Command-line tool, WebAssembly embedding

The techxt converter library is written in Rust, and is based on the techy parser library, designed to parse (La)TeX-like construct code. Both libraries can be compiled to WebAssembly (WASM), facilitating their embedding in the browser.

This web application

This web application runs entirely in the browser; no document is ever uploaded. You can install it as a Progressive Web App on your phone and on your desktop.

Get it

The Rust library:

[dependencies]
techxt = { git = "https://github.com/phfaist/techxt", rev = "..." }

The command-line program:

cd rust
cargo run --bin techxt -- --wrap 78 paper.tex -o paper.txt

      Install techxt

      techxt is a progressive web app: install it and it gets its own window and its own icon, starts without a browser bar, and keeps working with the network off. Nothing is uploaded when you install it — the whole converter is already in this page.

      You are already running the installed app.

      On iPhone and iPad

      1. Open this page in Safari — other iOS browsers cannot install it.
      2. Tap the Share button in the toolbar.
      3. Choose Add to Home Screen, then Add.

      On Android

      1. Open the browser menu (⋮).
      2. Choose Install app, or Add to Home screen where that is what it is called.

      On a desktop, in Chrome or Edge

      1. Click the install icon at the right of the address bar — a screen with an arrow.
      2. Or open the browser menu and choose Install techxt (under Cast, save and share in recent Chrome).

      On a Mac, in Safari

      1. Open the File menu.
      2. Choose Add to Dock (Safari 17 and later).

      In Firefox

      Firefox on the desktop does not install web apps. (Try maybe a different browser for this purpose.) The page still works offline once you have opened it, and bookmarking it is enough to come back without a network. On Android, use Add to Home screen in the menu.

      In this browser

      Look for Install or Add to Home screen in the browser’s menu. If neither is there, the page still works offline once it has been opened, and a bookmark is enough to return to it.

      What an installed copy adds

      • It opens in its own window, without a browser bar.
      • It starts with the network off, converter and all.
      • It can open a .tex file straight from the file manager.
      • On Android it appears in the share sheet, so selected LaTeX can be sent to it.

      Display fonts are fetched as you choose them. Keep all fonts offline, in More options, fetches all five now so they work with the network off too.
