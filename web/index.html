techxt

LaTeX-like markup → plain text

About GitHub

What this is

techxt converts documents written in a LaTeX-like language into readable plain text: \emph{hi} becomes ℎ𝑖, \"o becomes ö, $\sum_{i=1}^n x_i$ becomes ∑ᵢ₌₁ⁿ 𝑥ᵢ, an itemize becomes a bulleted list, and a tabular becomes an aligned text table.

Content conversion and text layout are separate stages, so wrapping, blank lines and indentation are decided once from complete information instead of macro by macro. Unknown constructs and skipped content produce structured diagnostics with source positions rather than silent surprises — the panel under the panes is showing you the same reports the command-line program prints.

Your document stays here

Everything runs in your browser. No document is ever uploaded, and the page makes no third-party network requests at all — no CDN, no analytics, no error reporting. Install it from your browser’s menu and it works with the network off.

Get it

The Rust library:

[dependencies]
techxt = { git = "https://github.com/phfaist/techxt", rev = "..." }

The command-line program:

cd rust
cargo run --bin techxt -- --wrap 78 paper.tex -o paper.txt
