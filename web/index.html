About techxt

Techxt — LaTeX to unicode text converter

Convert LaTeX code into a readable plain text approximation: \emph{hi} becomes ℎ𝑖, \"o becomes ö, $\sum_{i=1}^n x_i$ becomes ∑ᵢ₌₁ⁿ 𝑥ᵢ, an itemize becomes a bulleted list, and a tabular becomes an aligned text table. Your own \newcommand and \def definitions are expanded where you use them.

This web application runs entirely in the browser

No input data is uploaded to any server. You can install this app as a Progressive Web App on your phone and on your desktop (read more).

Every document you convert is kept in your library, which is stored on this device only and is never uploaded. Nothing in it is ever removed to save space: you delete what you want gone, and Export writes the whole library to a file you keep.

Rust libraries techy and techxt, successors to python's pylatexenc

The techxt converter library is written in Rust. It is based on the techy parser library, designed to parse (La)TeX-like construct code. Both libraries can be compiled to WebAssembly (WASM), facilitating their embedding in the browser (as you can see on this page).

The techy and techxt libraries are the result of rewriting the pylatexenc python library capabilities from scratch, in Rust. We've improved the design and made the parsing faster.

Techy: github project | Techxt: github project | Pylatexenc: github project

The techy/techxt libraries are currently in early development stage.

The techxt command-line tool

Prefer the command line? Download/clone the techxt repository, and install the binary:

techxt$ cargo install --path rust/techxt-cli

Then:

$ techxt myfile.tex 
Here is some math: ∑ₖ₌₁ⁿ 1/𝑘² …

      Install the techxt app

      techxt is a progressive web app: install it and it gets its own window and its own icon, starts without a browser bar, and keeps working with the network off. Nothing is uploaded when you install it — the whole converter is already in this page.

      You are already running the installed app.

      On iPhone and iPad

      1. Open this page in Safari — other iOS browsers cannot install it.
      2. Tap the Share button in the toolbar.
      3. Choose Add to Home Screen, then Add.

      On Android

      1. Open the browser menu (⋮).
      2. Choose Install app, or Add to Home screen where that is what it is called.

      On a desktop, in Chrome or Edge

      1. Click the install icon at the right of the address bar — a screen with an arrow.
      2. Or open the browser menu and choose Install techxt (under Cast, save and share in recent Chrome).

      On a Mac, in Safari

      1. Open the File menu.
      2. Choose Add to Dock (Safari 17 and later).

      In Firefox

      Firefox on the desktop does not install web apps. (Try maybe a different browser for this purpose.) The page still works offline once you have opened it, and bookmarking it is enough to come back without a network. On Android, use Add to Home screen in the menu.

      In this browser

      Look for Install or Add to Home screen in the browser’s menu. If neither is there, the page still works offline once it has been opened, and a bookmark is enough to return to it.

      Other devices

      What an installed copy adds

      • It opens in its own window, without a browser bar.
      • It starts with the network off, converter and all.
      • It fetches the MathJax typesetter quietly on each start, from this same site, so Math: MathJax works offline as well.
      • It can open a .tex file straight from the file manager.
      • On Android it appears in the share sheet, so selected LaTeX can be sent to it.

      Display fonts are fetched as you choose them, and the MathJax typesetter the first time you choose that math mode — from this site, never from anyone else’s. Keep everything offline, in More options, fetches all of it now so it works with the network off too.
